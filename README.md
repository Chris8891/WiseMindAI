# WiseMind AI✨

WiseMindAI 是一款**本地优先的 AI 学习与知识工作台**。将文档中心、知识库、AI 工作台、笔记中心、知识卡片、AI 考试、学习统计、海报与信息图等模块放进同一套工作流里，让资料处理、知识沉淀和成果输出都在一个地方完成。

WiseMindAI 为学生、教师、内容创作者和职场人士提供一个**一体化的 AI 学习系统 + 私人知识资产空间**，让知识从收集到输出尽量少切换、少丢失上下文，也更容易长期积累。

## 1. 产品定位

WiseMindAI 不是把 AI 能力零散塞进很多页面里，而是按真实使用流程组织产品：

1. **收集知识**：把文档、链接、图片、网页、音视频等资料统一放进文档中心。
2. **沉淀知识**：把相关资料沉淀进知识库、笔记中心和知识卡片。
3. **加工知识**：通过 AI 工作台、单文档对话、知识库对话、AI 搜索和翻译等能力继续理解内容。
4. **知识复盘输出**：用 AI 考试和学习统计检查掌握情况，再输出为笔记、海报、信息图或其他分享成果。

## 2. 当前核心模块

- **文件文档**：统一导入、分类、预览和处理资料，是文档总结、单文档对话、生成笔记、考试和信息图的主入口。
- **AI 知识库**：围绕专题聚合多份资料，支持跨文档分析、总结、对话、考试和信息图生成。
- **AI 工作台**：承接独立 AI 对话、多轮交流、内容生成和临时任务处理。
- **AI 笔记**：保存、编辑、整理和加工自己的内容，也可以把文件总结和 AI 结果沉淀成笔记继续创作。
- **知识卡片**：将资料和笔记里的知识点拆成可学习、可复习、可追踪的小单元。
- **AI 考试**：基于文档、知识库、卡片或手动输入内容生成试卷，并给出分析报告。
- **学习统计**：从资料处理到考试结果，持续记录学习行为和完成情况。
- **海报与信息图**：把总结、笔记或知识库内容转成更适合表达和分享的视觉化成果。
- **浏览器扩展与网页剪藏**：在浏览器里直接保存链接、划词、知识卡片、网页 PDF 和截图。
- **数据备份与同步**：支持本地备份、云端备份和数据恢复，保护长期积累的知识资产。
- **开放接口与外部集成**：支持本地 API、MCP 服务、插件和外部工具协同。
- **AI 模型与能力配置**：为总结、对话、考试、图像生成等场景提供底层模型支持。
- **沉浸式翻译与效率工具**：提升日常阅读、记录和任务处理效率。

## 3. 核心价值

WiseMindAI 的核心价值：

1. **本地优先，隐私可控**：知识长期沉淀在自己的本地设备和备份体系里。
2. **模块清晰，入口统一**：用户更容易按真实任务找到功能，而不是到处记按钮名。
3. **从收集到输出一条线完成**：文件、知识库、笔记、卡片、考试和视觉输出天然串联。
4. **学习闭环更完整**：不只是“看过”，还包括整理、练习、检验和复盘。
5. **开放能力更强**：支持多模型、MCP、本地 API 和插件，能接进更完整的个人工作流。
